Atelier Board v2.0
既存のGitHub Pagesリポジトリの index.html、sw.js、manifest.webmanifest を更新してください。更新前に書き出しでバックアップしてください。ZIPは新規設置用の全6ファイルです。

v2.0:
・iOSステータスバーの指定色を薄いグレー #F2F1F4 に固定し、ボード背景色から分離。すりガラス回避処理は維持。
・グループボタンを一時的な選択モードへ変更。空白をドラッグして囲む、個別タップで追加・解除、選択済みアイテムをドラッグして一括移動。空白タップでは解除しない。ボタン再押下で終了。ロック中・カラム内アイテムは対象外（カラム本体はロックがなければ移動可能）。旧グループ情報は保持するが一括移動には使用しない。
・角丸ON時の半径を12 CSS pxで統一。カラムのアイテム数を11pxで固定。
・カラム内のボードの背景半透明（50%）切り替え。カラム内アイテムの固有ツールバーは2列。
・ボード名はキャンバスタップ/Enterで確定。親ボードからの階層表示。
・v1.9のキーボード設定を維持（歯車 → キーボード）。TourBox Consoleの既存設定を変更する必要なし。

ChromiumのHTML直接読み込みで、グループ範囲選択・追加・移動・取り消し・解除、色指定、カラムの文字サイズ・2列・半透明、階層表示・名前確定、キー受信・ズームを確認。ローカルHTTPへのアクセス制限により実際のIndexedDB保存、Service Worker更新、iOS実機は未検証。
