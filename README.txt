Atelier Board v1.0

GitHub Pages：index.html、sw.js、manifest.webmanifest、アイコン2枚を配置。
既存リポジトリは index.html と sw.js を更新。更新前に必ず「書出」でバックアップしてください。

変更点
・画像データをIndexedDBにBlobとして保存。旧Base64画像は起動時・JSON読込時にBlobに変換。既存URL参照は維持、新規URL参照は追加しない。
・取り込み画質：オリジナル、長辺最大2048px、長辺最大1024px。縮小時はJPEG（品質0.92）またはPNG。縮小時はアニメーションが静止画になる。
・保存後の画像解像度の70%で初期配置。縦横比固定、選択時に解像度と倍率を表示。旧画像は以前の枠に収まる縦横比へ補正。
・画像保存は保存済みの画像データを共有またはダウンロード。トリミングは表示範囲のみの編集、原画は保持。
・上部：整列、背景色（選択なし）、レイヤー順、複製、ロック、角丸、接続、削除。左：アイテム追加、または固有操作。カラム内のアイテムのレイヤーはカラム単位で移動。
・ステッカー：仮の8種類の記号、画像ファイルから追加。
・書出は従来のJSON形式で画像も含める（書き出し時のみBase64）。新規ZIPデータバックアップと全体の画像重複排除は未実装。

検証：ChromiumにHTMLを直接読み込んで動作確認。iPadのPWA、IndexedDBの永続保存・実際の更新移行は未検証。
