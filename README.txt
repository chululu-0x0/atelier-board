Atelier Board v0.2 / 試作品
GitHub Pages: 新規リポジトリのルートにこのZIP内のファイルをすべて置き、Settings > Pages > Deploy from a branch > main / root を選択。公開されたHTTPS URLをiPadのSafariで開き、共有メニューからホーム画面に追加。
画像ドロップは画像ファイル、HTML内の画像URL、URI、テキストを順に判定。画像を取得できない場合は外部参照またはリンクにする。外部参照はオフライン利用不可の場合がある。
IndexedDBに保存。端末やブラウザをまたぐ同期なし。書出・読込でバックアップ可能。書出は外部参照の画像データ自体を含まない。プライベートモード等では保存できない場合あり。
試作段階につきiPad実機でのドラッグ・ピンチ等の挙動は未確認。ローカルHTMLプレビューではPWA化できないためHTTPSで配信して検証する。

更新時は同じリポジトリ内の index.html と sw.js を上書き。既存IndexedDBをそのまま使用します。更新前に書出を推奨。古い画面が出る場合はSafari/PWAを閉じて再度開いてください。
取り消し履歴は起動中の最大60操作（再起動後は保持しない）。接続線は四辺中央のアンカーを選択して作成。線を選択して実線/破線、矢印あり/なしを変更できます。
