Atelier Board v1.1
GitHub Pages 用 PWA。既存リポジトリの index.html と sw.js を更新してください。
更新前に v1.0 の「書出」から JSON バックアップを取ってください。

変更点
・新規画像は長辺400 CSS px、ステッカーは従来通り128px。保存画像の解像度は変更しません。
・トリミングは8個のハンドルをドラッグ、枠の中をドラッグして移動。非破壊編集。
・パレットの選択中の色をタップして標準カラーピッカーを開く。左側のアイコンで配置方向・列数を切替。編集中は変更を即時プレビュー、完了で確定、キャンセルで元に戻る。7色以上は2列。
・編集中のパレット用スポイトは左側のアイコンから利用。
・画面下部にボード名（入力で変更）、親ボードに戻るボタン、バージョン、ズームプリセット、右下に書き出し／読み込みメニュー。
・上部の操作バーに取り消し・やり直し。キャンバス上の2本指タップ・3本指タップでも操作可能（移動・ピンチ・入力中は対象外）。OS側のジェスチャーが優先される場合があります。
・タップハイライトを抑制、状態切替ボタンの幅を固定。
・Blob保存、従来のJSONバックアップ形式、2D Matrix描画は維持。

検証: ChromiumにHTMLを直接読み込んで動作確認。iPad実機、サービスワーカー更新、IndexedDB永続保存は未検証です。

v1.2: iOS上端ブラー回避実験（Qiita: https://qiita.com/na-trium-144/items/0add98a80ca2391e3f17 ）、回転ハンドル、曲線中央ハンドル、見出し、直接文字編集、フォント切替。
ロック中は回転不可。回転したアイテムはスマートガイド対象外。カラム回転時は内部アイテムも一緒に回転する。フォントは端末内蔵のものを使用し、未搭載時は代替フォントとなる。
